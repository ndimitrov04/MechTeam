## Introduction

Build a huge mech from scratch, then jump inside to manually operate its systems mid-combat. You can also hire a crew to control it for you, while you bail and infiltrate the enemy's mech to neutralize its pilots, control terminals, and combat modules.

## Gameplay

| Feature | Description |
| --------- | ------------- |
| 🏗️ Build a Mech | Construct your mech piece by piece from the ground up |
| 🕹️ Manual Control | Platform inside your mech to operate systems mid-combat |
| 👥 Hire a Crew | Let your team handle piloting while you go rogue |
| ⚔️ Infiltrate | Sneak into enemy mechs to disable pilots and modules |
| 💥 Fight & Upgrade | Destroy enemy mechs, survive, and enhance yours |

You can manually operate your mech's systems mid-combat by platforming inside of it. Alternatively, hire a crew to control it for you while you infiltrate the enemy's mech to neutralize its pilots, control terminals, and combat modules.

## Controls

| Input | Action |
| ------- | -------- |
| `WASD` | Move |
| `SPACE` | Jump |
| `F` | Interact |
| `CTRL` | Melee Attack |
| `Scroll Wheel` | Zoom In / Out |
| `ALT` | Scan |
| `P` | Pause |
